# Установка Oracle ADV 0.6.0

Нужны M5Stack Cardputer ADV с ESP32-S3, M5Apps и microSD FAT32.
Обычный Cardputer этой прошивкой не поддерживается.

## Язык и установка

По умолчанию сборка английская. Для русской выполните
`python tools/build_release.py --language ru`.
Готовые архивы: Oracle-ADV-0.6.0-en.zip, Oracle-ADV-0.6.0-ru.zip и
Oracle-ADV-0.6.0-zh.zip (упрощённый китайский, озвучка на путунхуа).

1. Распакуйте выбранный ZIP. Скопируйте его ORACLE в корень карты.
2. При обновлении сохраните личный ORACLE/config.json.
3. Положите BIN из того же архива в корень карты. Можно назвать его ORACLE.BIN.
4. Откройте M5Apps → Installer → SD и выберите BIN без префикса ._.
5. Запустите приложение. В шапке должны быть ORACLE / 06.0, батарея и SD.

При переходе с 0.5.x или смене языка нужно обновить **и прошивку, и ресурсы**.
Интерфейс, колода, озвучка, Таро и чеки используют язык сборки.
Смешанный комплект не загрузится: вместо чужой колоды включится резервная,
без голоса и печати. Обозначение DEMO также появляется, если SD недоступна.

Исходный sdcard/ содержит медиа и старый русский набор. Для установки используйте
ZIP или сгенерированную папку build/packs/en/ORACLE либо build/packs/ru/ORACLE или build/packs/zh/ORACLE.
Не копируйте сразу оба языка поверх друг друга.

## Управление

На главном экране лево/право (физические запятая и слеш без Fn) переключают темы,
остальные клавиши запускают прогноз. На результате N/Enter/пробел дают новый,
R повторяет голос, P печатает копию, I показывает картинку, A переключает
автопрокрутку. ;/W и ./S прокручивают текст. M выключает звук, +/- меняют громкость,
Esc возвращает назад. Физическая клавиша обратной кавычки работает как Esc.

В вопросе Таро Tab переключает раскладку RU/EN, Shift — регистр, Backspace удаляет
символ, Enter отправляет вопрос. Пустой вопрос даёт общий расклад.
Смена раскладки ввода не меняет язык интерфейса или ответа.

## Таро и печать

Для 120 готовых предсказаний ключи и интернет не нужны. Для Таро скопируйте
ORACLE/config.example.json в ORACLE/config.json и задайте свои Wi-Fi 2.4GHz,
HTTPS-хост LiteLLM, модель и токен. Файл с настоящими данными не входит в Git
или публичный ZIP. На SD нужен комплектный ORACLE/tls/roots.pem.
Таро даёт текст и чек; озвучки нового сетевого ответа пока нет.

На BQ95 откройте экран FunPrint с QR-кодом и отключите автовыключение.
При раскрытии прогноза выполняется одна автоматическая попытка печати.
P запускает поиск заново или печатает дополнительную копию того же результата.
После обрыва сначала проверьте бумагу: частичный чек сам не повторяется.
Драйвер настроен на проверенный экземпляр BQ95; для другого потребуется
изменить его идентификатор в firmware/src/bq95_printer.cpp.

## Диагностика

После перезапуска ORACLE/diagnostic.txt содержит причину сброса и предыдущий этап,
если сохранилась RTC-память. Вопрос, пароль и токен туда не записываются.
Загружайте application image, а не bootloader или полный flash-образ.
Лимит application image для M5Apps — 1 310 720 байт.

Все три языковые версии проверяются программно. Голос, Wi-Fi, батарею и физическую
печать новой прошивки ещё нужно подтвердить на самом Cardputer.

## Первая установка: устройство и карта — два отдельных шага

Если M5Apps ещё нет, сначала установите этот загрузчик через USB-кабель с передачей
данных. В [M5Burner](https://docs.m5stack.com/en/download) откройте группу CardPuter,
выберите M5Apps с поддержкой ADV и следуйте инструкции записи.
[Инструкция автора M5Apps](https://github.com/d4rkmen/M5Apps#installation).
Установка загрузчика заменяет текущую прошивку: заранее сохраните нужные данные.
Oracle BIN — образ приложения, его нельзя записывать как полный образ с адреса 0x0.

Если компьютер не видит порт, зарядка не доказывает исправность передачи данных:
проверьте другой кабель и прямое подключение без хаба. Для режима загрузки ADV
следуйте [инструкции M5Stack](https://docs.m5stack.com/en/uiflow2/cardputer-adv/program).
После установки M5Apps кабель данных больше не нужен для обычных обновлений Oracle:
достаточно кардридера. Для готового ZIP не нужны Python, PlatformIO или ElevenLabs.

1. Выключите Cardputer и извлеките microSD. Подключите её через кардридер.
2. Сделайте резервную копию. Используйте FAT32; форматирование удаляет содержимое
   и не требуется, если карта уже работает в FAT32. Проверьте, что выбран именно
   накопитель microSD, а не другой диск компьютера.
3. Распакуйте ZIP на компьютере. На карте должно хватать места на распакованные файлы.
4. Скопируйте **весь ORACLE** и BIN из одного архива прямо в корень карты.
5. Безопасно извлеките карту, вставьте в выключенное устройство и включите его.
6. В M5Apps откройте Installer → SD, установите корневой BIN и запустите приложение.
   Одного копирования BIN недостаточно: его нужно установить через Installer.
7. Проверьте SD в шапке, язык текста, картинку и голос на обычном предсказании.

## Точная структура microSD

Пример для русского набора:

```text
корень microSD/
├── Oracle-ADV-0.6.0-ru.bin
└── ORACLE/
    ├── index.json
    ├── cards/coat.json
    ├── images/… .jpg
    ├── audio/coat.wav
    ├── print/coat.bin
    ├── config.example.json
    ├── tls/roots.pem
    └── config.json          # создаётся пользователем, необязателен
```

Английская озвучка лежит в audio/en/, китайская — в audio/zh/. В китайском наборе
также нужен fonts/chinese12.bin. Не меняйте структуру архива и имена файлов.
ORACLE должен находиться непосредственно в корне, без дополнительной папки
Oracle-ADV-…/ и без вложенности ORACLE/ORACLE/. Название тома карты несущественно.

| Файл или папка внутри ORACLE | Назначение |
| --- | --- |
| index.json | Язык, список карточек и темы; должен соответствовать BIN |
| cards/*.json | Текст, заголовок и пути к ресурсам каждой карточки |
| images/*.jpg | Картинки на экране |
| audio/ и вложенные папки | Готовые WAV выбранного языка |
| print/*.bin | Растры чеков; это **не прошивка**, не выбирайте их в Installer |
| fonts/chinese12.bin | Полный китайский шрифт для дополнительных символов Таро; не прошивка |
| config.example.json | Публичный шаблон с заглушками |
| config.json | Личные сети Wi-Fi и токен LiteLLM; хранить приватно |
| tls/roots.pem | Корневые сертификаты HTTPS, нужны для Таро |
| diagnostic.txt | Диагностика последнего запуска/сброса, создаётся устройством |

Корневой установочный BIN после установки можно убрать или оставить для повторной
установки. ORACLE нужен для повседневной работы. README.md, SHA256SUMS и third_party/
сохраните вместе с архивом на компьютере: устройство их не читает. Метаданные JSON
рядом с WAV в исходниках на карте не требуются. Магические эффекты находятся в прошивке.

## Обновление, смена языка и откат

Сначала сохраните старый рабочий ZIP и копию ORACLE, особенно config.json.
Замените папку ресурсов целиком новым комплектом, затем верните в неё личный
config.json. Сохраните остальные папки M5Apps на карте. Операция «заменить папку»
в файловом менеджере может удалить старое содержимое, поэтому резервная копия важна.
Установите BIN из того же ZIP. Для отката восстановите старые BIN и ORACLE вместе.

В /ORACLE одновременно активен один язык. Меню переключения языка нет; Tab меняет
только раскладку вопроса. Для китайского вопрос пока вводится английскими буквами
или пиньинем, ответ будет китайским; китайского IME ещё нет.

## Личный конфиг и частые ошибки

Для Таро скопируйте config.example.json в config.json и замените все заглушки.
Редактируйте обычный UTF-8 JSON без комментариев; проверьте, что имя не стало
config.json.txt. wifi содержит 1–4 сети в порядке предпочтения. host — имя сервера
без https://, порта и пути; запрос идёт на /v1/responses. model должен быть доступен
вашему ключу LiteLLM. Настройки Wi-Fi в M5Apps не заменяют config.json Oracle.
Экран ручного выбора сети и сохранения нового пароля в Oracle пока не реализован.

| Проблема | Что проверить |
| --- | --- |
| Chip id mismatch | ADV/ESP32-S3 и настоящий корневой Oracle BIN, а не файл чека или шрифта; не обходите проверку чипа |
| DEMO вместо SD | FAT32, контакт карты, /ORACLE/index.json и одинаковый язык BIN и ресурсов |
| Нет голоса | SD в шапке, M для снятия mute, + для громкости, пути WAV; R на обычном результате. Сетевое Таро без озвучки |
| Не видит Wi-Fi | Точное имя сети, включённая точка доступа, диапазон 2.4 GHz; на поддерживаемом iPhone — «Максимальная совместимость» |
| Ошибка Таро | JSON, доступность прокси, токен и модель, roots.pem и синхронизация времени |
| Нет печати | QR-экран FunPrint на BQ95, автовыключение, бумага и батарея; затем P |
| Ошибка NVS при печати | Обновите Oracle BIN; не стирайте настройки загрузчика как первый способ исправления |
| Сброс после нажатия | Текущие BIN/ресурсы, заряд и карта; сохраните diagnostic.txt и укажите момент сбоя |

Перед отправкой диагностики исключите config.json с паролями и ключом.
