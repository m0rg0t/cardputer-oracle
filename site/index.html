Четвёртая тема

А если вопрос слишком конкретный?

В «Таро / AI» можно набрать вопрос на клавиатуре. Оракул выберет три разных старших аркана — прошлое, настоящее и будущее — и запросит шутливое толкование через LiteLLM. Для этого режима нужны Wi-Fi и собственный ключ. Озвучка пока есть у готовых предсказаний.

Магия с понятным устройством

Немного нейросетей.
Много заготовленной судьбы.

  1. Выбираем тему

    Лево и право переключают колоды. Остальные кнопки на главном экране запускают предсказание.

  2. Тасуем вероятности

    Короткая анимация и магические звуки, которые синтезируются прямо на устройстве. У каждой темы своя очередь без повторов.

  3. Слушаем и читаем

    С SD загружается только выбранная карточка. На экране — картинка, затем прокручиваемый текст. Голос записан заранее в ElevenLabs.

  4. Забираем на бумаге

    Одна автоматическая попытка печати на BQ95 по Bluetooth. Клавиша P — ещё одна копия того же предсказания.

Собрать своего оракула

Колода, голос
и код — вместе.

Нужны Cardputer ADV, microSD с FAT32 и M5Apps. В проекте уже есть все тексты, WAV, картинки и готовые растры чеков. Повторно генерировать контент не требуется.

Сборки доступны на английском, русском и упрощённом китайском. Проверки на компьютере выполнены; установку, звук и радио нужно проверить на своём Cardputer ADV.

Локальная сборка

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install platformio
python tools/build_release.py
# Русский: --language ru
# 中文: --language zh

Установка — M5Apps → Installer → SD. В корень microSD скопируйте BIN и целиком папку ORACLE из одного языкового ZIP. Исходный sdcard/ не является готовым английским или китайским набором.

Если M5Apps ещё нет, сначала установите его по USB с кабелем данных. Для дальнейших установок Oracle достаточно кардридера. Формат карты — FAT32. После установки в шапке должно быть SD; DEMO означает, что полный набор не загрузился.

Сохраняйте личный ORACLE/config.json при обновлении. Файлы ORACLE/print/*.bin и ORACLE/fonts/chinese12.bin — ресурсы, не прошивки. Полные инструкции: подготовка карты, дерево файлов, Wi-Fi, обновление и диагностика.
